Send completed form responses to your backend and store them as JSON. The server returns the saved response's ID to confirm success.
  • Enter your email and a message. Both fields are required.
  • Press Send message. The completion screen shows Sending your message... until the server confirms the save, then displays the response's ID.
  • Open Requests and expand POST /api/responses to inspect the request body and the server's response. Then open Data to find the saved record with the same ID.
  • If saving fails, an error message appears. Press Try again to resend your answers.
  • Press Start over to clear the form and submit another response.
