Load form schemas and user variables from your Java backend, either embedded in HTML or fetched from an API. Use variables to personalize form text and control question visibility, and restore saved answers through the API to prefill the form.
  • Choose Schema embedded in HTML to receive the schema and user variables with the page, or Load from the API to fetch them and any saved answers in a separate request. You can inspect the API call in Requests.
  • Switch Customer between Alice and Bob. User variables personalize the title with their name and plan and show priority handling only for the premium plan.
  • When using Load from the API, you can select a Saved response to prefill the form with the customer's answers.
  • Press Submit claim to save a new response. Open Data to inspect the saved answers; user variables are excluded.
  • Press Start over to clear the form and the saved response selection.
